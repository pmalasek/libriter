# Barevné varianty loga

Vytvořeno vestavěným nástrojem `image_gen` z původních souborů
`libriter-logo-light.png` a `libriter-logo-dark.png`. Tyrkysové téma používá originály.

## blue / light

Output: `libriter-logo-blue-light.png`

```text
Use case: precise-object-edit.
Asset type: Libriter application logo, blue color scheme, light UI mode.
Input image: edit target, the existing official Libriter logo.
Primary request: Recolor ONLY the teal/cyan colored pixels into deep sapphire blue and navy gradients, darker lettering for a white background, sky blue play triangle and colored book lines. Keep existing tonal structure and gradient shading.
Text (verbatim): "Libriter". Keep typography, every letter contour, icon shapes, headphones, play triangle, open book, spacing, proportions, position and original composition exactly unchanged. Keep white parts white.
Background: genuinely transparent alpha, including holes between and inside letters. No solid backdrop, no checkerboard painted into the image.
Constraints: this is strictly a color variant of the original, not a redesign. Keep the full horizontal icon and wordmark, ideally original canvas 1672x941 with original transparent padding. No new details, shadows, borders, embellishments, or additional text. Output one logo asset.
```
